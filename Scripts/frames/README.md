# 프레임 장식 에셋

`renderDecor.swift`가 프레임 장식 PNG를 굽는다. 결과물은 **cutin-backend가 배포하는 자산**이고
(`assets/frames/`), 앱은 `GET /frames`가 준 URL로 내려받아 합성 마지막에 얹는다.

## 왜 서버 자산인가

프레임 계약은 원래 색과 길이뿐이었다(배경·전경·여백·거터·라운딩·푸터). 그 값만으로는 하트도
곰돌이도 그릴 수 없어서 "귀여운 프레임"이 색 바꾸기에서 멈춘다. 장식을 그림으로 받으면 외형을
늘릴 때 **앱을 다시 배포하지 않는다** — 서버 시드(`seedFrames.ts`)만 바뀐다.

## 굽기

```bash
swift Scripts/frames/renderDecor.swift <자산 폴더> [목업 폴더]
```

```bash
# 실제 배포 위치로
swift Scripts/frames/renderDecor.swift ~/orca/workspaces/cutin-backend/dev/assets/frames /tmp/frame-mock
```

목업 폴더를 생략하면 자산 폴더 아래 `mock/`에 떨어진다. **자산 폴더에 목업을 섞지 말 것** —
그대로 서버에 올라간다.

## 나오는 것

세트마다 최대 3장 + 확인용 목업 1장이다.

| 파일 | 쓰임 | 크기 |
|---|---|---|
| `<code>-top.png` | 그리드 **위 밴드** — 폭 100%로 늘어난다 | 1080 × 190 |
| `<code>-bottom.png` | 그리드 아래·푸터 위 밴드 | 1080 × 150 |
| `<code>-pattern.png` | 배경 위에 까는 타일 (없는 세트도 있다) | 180 × 180 |
| `mock/<code>.png` | 실제 합성 순서로 구운 확인용 그림 | — |

스트립은 **폭 100%가 계약**이라 좌우 여백을 그림이 갖는다. 높이는 그림 비율을 따르므로 템플릿
비율(`1:1`·`1:3`…)이 달라져도 장식이 늘어나지 않는다.

## 앱이 그리는 순서

`CutCompositor.render`가 이 순서로 굽는다. 목업도 같은 계산을 쓴다.

```
[상단 밴드][padding][그리드][하단 밴드][푸터][padding]

배경색 → 패턴 타일 → 컷 → 상단 밴드 → 하단 밴드 → 푸터(CUTIN·날짜)
```

**장식은 컷 위에 겹치지 않는다.** 밴드가 제 자리를 갖고, 합성기가 캔버스를 그만큼 늘린다.

**장식이 없는 프레임도 같은 밴드를 비운다.** 장식 있는 프레임만 길어지면 프레임을 바꿀 때마다
결과물 규격과 사진 크기가 달라지기 때문이다(사용자 결정 2026-08-25). 그래서 밴드 높이는 그림이
아니라 앱의 상수가 정한다 — `CutCompositor.topBandRatio`·`bottomBandRatio`. **이 스크립트의
`topHeight`·`bottomHeight`와 같은 값이어야 한다.** 갈리면 장식이 밴드에 맞춰 늘거나 줄어
비율이 뭉개진다.

## 새 세트를 추가하려면

1. `renderDecor.swift`의 `decors` 배열에 `Decor`를 하나 더 넣는다. 색은 목업에만 쓰이지만
   **서버 시드에 넣을 값과 같게 적어 둔다** — 두 곳이 갈리면 목업이 거짓말을 한다.
2. 위 명령으로 굽는다.
3. cutin-backend `src/db/seedFrames.ts`에 `decorated`를 펴서 항목을 추가하고 `pnpm db:seed`.
   **새 외형은 배열 뒤에 붙인다** — 첫 항목이 기본 외형이라, 앞에 끼우면 외형을 고르지 않은
   기존 포스트가 전부 달라 보인다.

`decorated` 프레임은 **여백을 `standard`에서 그대로 가져오고 거터·라운딩만 0으로 덮는다.**

- 여백이 같아야 프레임을 바꿔도 **사진 크기가 그대로**다. 값을 베껴 적으면 한쪽만 고쳤을 때 갈린다.
- 컷이 서로 맞닿아 하나의 사각형이 되고, 그 모서리가 프레임과 딱 맞물린다. 틈과 둥근 모서리가
  있으면 컷이 프레임 위에 어중간하게 얹힌 것처럼 보인다(포토매틱 스트립 참조).

## SVG를 쓰지 않는 이유

이 맥에는 SVG 변환기가 없다(`rsvg-convert`·ImageMagick·Inkscape 모두 부재). 새로 설치하는 대신
`Scripts/audit/montage.swift`가 이미 만들어 둔 관행 — CoreGraphics 스크립트로 이미지를 굽는 —
을 따랐다. 도형은 전부 코드라 색·배치를 바꾸고 다시 굽는 것이 빠르다.
